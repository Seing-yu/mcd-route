## 二、简介文案（直接复制）

### 一句话版（填「项目名称」旁的一行）

```
告诉你「这一顿该点外送还是自己跑一趟」的网页应用
```

### 详细版（填「项目简介」）

```
一个能回答「今晚点外卖，还是自己跑一趟？」的网页应用。

拖动配送费、起送价、每分钟时间成本，立刻看到两个渠道的到手价对比与建议。

它解决的是被所有点餐助手忽略的问题：券是绑商品、还分渠道的——一张到店券在外送场景根本用不了；再加上打包费、起送价和你的时间成本，差价常常不在你以为的地方。

同一个购物篮，「不在乎时间」和「时薪 100 元」会得到相反的结论。它不告诉你哪个便宜，它告诉你哪个对你更划算。

纯静态单页：零安装、零 Token、零采集、不联网，数据来自 2026-10-23 的真实麦当劳 MCP 调用。
```

> ⚠️ **和麦当劳赛的简介刻意区分**：这里**不提 Skill、不提 GitHub**，
> 强调「网页应用 + 场景价值 + 使用体验」——对应造物挑战的三个评审维度
> （创意与场景价值 35 / 作品完成度 40 / 使用体验 25）。

## 三、截图怎么截（3 张，对应 3 个评分维度）

### 第 1 张 · 顶部引导 + 结论卡 → 打「使用体验 25 分」

截取范围：页面从顶部到结论卡结束。

包含：
- 标题「麦门渠道官 · 在线试算」
- 「三步算出…」引导区
- 绿色结论卡（建议到店自取 / 到手价 / 净省多少）

> 建议先点「载入真实实采数据」再截，这样结论卡里是真实数字不是样例。

### 第 2 张 · 场景故事区 → 打「创意与场景价值 35 分」

截取范围：「一个具体的场景」整块。

包含：
- 左栏「你」：外送 ¥46.50、配送费打包费 ¥8.8、到店券用不了、门店 312 米
- 右栏「麦门渠道官」：券能抵 10.6、到手 ¥35.90、比外送少 11.4 元
- 底部那句「同一单饭，换个人的时间观，答案就变了」

> 这一张是**最关键的一张**——它一句话说清了「为什么这个题值得做」。

### 第 3 张 · 计价拆解 + 券体检 → 打「作品完成度 40 分」

截取范围：「第 3 步 · 看结论」到「券体检」结束。

包含：
- 计价拆解表（商品原价 / 用券抵扣 / 配送费 / 到手价 / 时间成本 / 总成本 / 是否可下单）
- 券体检表（名义面额 / 实际能用 / 结论）

### 截图纪律

| ✅ 要 | ❌ 不要 |
|---|---|
| 浏览器全屏（隐藏书签栏） | 任何 Token / 账号信息 |
| 缩放 100%，字看得清 | 个人地址、手机号 |
| 只截页面内容 | 桌面壁纸、其他标签页 |
| 真实数据模式（更有说服力） | 无意义的空白/报错 |
